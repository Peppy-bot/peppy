This is the command line tool used to run commands from the command line and run the peppy service in the background.
The following commands are available:
 - [[node]] : Command related to [[PeppyOS]] nodes
 - [[serve]]: Starts the background service that listen to changes in node configuration and node communication
 - `pixi`: [Pixi](https://pixi.sh/latest/) related commands. Exposes the pixi library to the user to modify his virtual environement
 - [[sync]] : Force sync the running service with the local node configurations
