# Contributing to peppy

## Issues

Anyone with a GitHub account can open an issue in this repository, to report a bug, to ask a
question, or to propose a change:
<https://github.com/Peppy-bot/peppy/issues/new>

In a bug report, give:

- the peppy version, from `peppy --version`,
- the operating system and the CPU architecture of the machine,
- the steps that cause the problem,
- what you expected, what happened instead, and the error output or the logs.

## Pull requests

Only the Peppy team opens pull requests in this repository: GitHub lets only the accounts with
write access to it open one. To propose a change, open an issue that describes it.
