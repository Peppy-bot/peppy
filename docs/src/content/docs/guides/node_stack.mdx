## Adding your node to the stack

Add your node to the PeppyOS stack:

```sh
peppy add .
```

This command registers your node with the master node and makes it available for execution.

## Starting your node

Start your node:

```sh
peppy start my-first-node
```

You should see output indicating your node is running.

## Checking node status

View all running nodes:

```sh
peppy list
```

## Stopping your node

When you're done, stop your node:

```sh
peppy stop my-first-node
```
