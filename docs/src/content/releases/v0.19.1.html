v0.19.1 https://docs.peppy.bot/releases/v0-19-1/ 2026-07-25T00:00:00Z Peppy tightens how container nodes handle host and temp paths, and adds a Quickstart from install to a simulated arm. <article> <header> <h1>v0.19.1</h1> <p><em>Peppy tightens how container nodes handle host and temp paths, and adds a Quickstart from install to a simulated arm.</em></p> <p><small> Released on July 25, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>Container nodes no longer inherit the caller's temporary directory. If a container node relied on that path, provide it explicitly.</li> <li>Peppy no longer auto-creates bind mount source paths that the host is expected to provide. Create those directories before starting the node, or the mount will fail.</li> </ul> <h3>Container and host-runtime behavior</h3> <ul> <li>When a host runtime path is not available inside the VM, peppy now reports the actual constraint instead of a less specific error.</li> <li>Closed a case where a run command could bypass the restrictions on host runtime paths.</li> </ul> <h3>Documentation</h3> <ul> <li>Added a Quickstart that walks you from installing peppy to a simulated OpenArm in three steps.</li> </ul> </article>
