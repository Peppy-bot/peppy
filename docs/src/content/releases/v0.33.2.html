v0.33.2 https://docs.peppy.bot/releases/v0-33-2/ 2026-10-13T00:00:00Z Peppy now installs on Debian 13 and the Raspberry Pi 5, and requires 64-bit Linux with glibc 2.38 or later. <article> <header> <h1>v0.33.2</h1> <p><em>Peppy now installs on Debian 13 and the Raspberry Pi 5, and requires 64-bit Linux with glibc 2.38 or later.</em></p> <p><small> Released on October 13, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li> <p>The Linux installer now requires a 64-bit system with glibc 2.38 or later, and stops on Ubuntu 22.04 and older Ubuntu-based systems it previously installed on.</p> </li> <li> <p>You can now install peppy on Debian 13 or later on x86_64 and aarch64.</p> </li> <li> <p>You can now install peppy on Raspberry Pi OS (64-bit) on the Raspberry Pi 5, Pi 500, and Compute Module 5.</p> </li> </ul> </article>
