v0.26.3 https://docs.peppy.bot/releases/v0-26-3/ 2026-08-31T00:00:00Z Adds `peppy repo search` and `repo show` to find any indexed item by regex and report who implements, consumes, or observes it. <article> <header> <h1>v0.26.3</h1> <p><em>Adds `peppy repo search` and `repo show` to find any indexed item by regex and report who implements, consumes, or observes it.</em></p> <p><small> Released on August 31, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>A bare launcher name (no path separator, no <code>.json5</code>) passed to <code>peppy stack launch</code> or <code>stack resolve</code> now resolves through the repository cache only, never a same-named file in the current directory; write <code>./name.json5</code> to launch a local file.</li> <li>Run <code>peppy repo refresh</code> after upgrading: peppy refuses a nodes cache written by an earlier release, and the commands that read it fail until it is rebuilt.</li> </ul> <h3>Repository search and inspection</h3> <ul> <li><code>peppy repo search &lt;name-regex&gt;[:&lt;tag-regex&gt;][@&lt;sha256&gt;]</code> finds any indexed node, launcher, contract, pairing, or MCP exposure by unanchored regex, listing each match's kind, repository, path, and fingerprint.</li> <li><code>peppy repo show &lt;query&gt;</code> reports every matched identity: where each document is published and, for a contract or pairing, the nodes that implement, consume, participate in, or observe it, with each pin's status.</li> <li>Both <code>repo search</code> and <code>repo show</code> accept <code>--json</code> for machine-readable output and read the local caches, so they need no daemon.</li> </ul> <h3>Other improvements</h3> <ul> <li><code>peppy stack list --json</code> prints the discovered core nodes and their stacks as one JSON document.</li> <li><code>stack list</code> panels and the <code>repo search</code> / <code>repo show</code> tables now fit the terminal, wrapping over-long cells inside the borders; piped output stays unwrapped.</li> <li>On Linux, replacing the <code>peppy</code> binary while the daemon runs no longer strands built-in MCP nodes: the daemon serves them from its running image, warns in the add log, and adopts the new binary on restart.</li> </ul> </article>
