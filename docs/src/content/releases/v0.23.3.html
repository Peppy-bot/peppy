v0.23.3 https://docs.peppy.bot/releases/v0-23-3/ 2026-08-15T00:00:00Z Adds the mcp_exposure/v1 format for generating MCP server nodes and task bridges, and keeps slow-connection launches alive. <article> <header> <h1>v0.23.3</h1> <p><em>Adds the mcp_exposure/v1 format for generating MCP server nodes and task bridges, and keeps slow-connection launches alive.</em></p> <p><small> Released on August 15, 2026 </small></p> </header> <h3>MCP exposure</h3> <ul> <li>The new <code>mcp_exposure/v1</code> format lets you declare MCP exposures, which peppy wires into the repository and publishes as exposure bundles.</li> <li>An exposure generates an MCP server node together with action-backed task bridges, whose feedback QoS is derived from the contract rather than a fixed default.</li> </ul> <h3>Launches and containers</h3> <ul> <li>Container <code>mount_paths</code> that start with <code>~</code> are now expanded to the home directory on the machine that binds them.</li> <li>Launches over slow connections stay alive by reporting genuine build progress instead of stalling.</li> </ul> <h3>Documentation</h3> <ul> <li>MCP exposure is now covered by its own dedicated advanced guide.</li> </ul> </article>
