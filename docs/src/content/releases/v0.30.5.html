v0.30.5 https://docs.peppy.bot/releases/v0-30-5/ 2026-09-22T00:00:00Z `peppy stack join` and `stack remove` now grow and shrink a running instance's producer and observer sets, delivered live to running nodes. <article> <header> <h1>v0.30.5</h1> <p><em>`peppy stack join` and `stack remove` now grow and shrink a running instance's producer and observer sets, delivered live to running nodes.</em></p> <p><small> Released on September 22, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li> <p><code>peppy stack list --json</code> now nests each <code>slot_bindings</code> producer under a <code>producer</code> key, with an optional <code>copy</code> key; update anything that parses that output.</p> </li> <li> <p>Rust generated <code>bound_producers()</code> accessors return owned values (<code>NonEmptyProducers</code>, <code>Vec&lt;ProducerRef&gt;</code>) instead of borrowed slices, so bind the result to a variable before calling <code>.first()</code>.</p> </li> <li> <p><code>peppy stack join</code> adds a copy's own instances to a running instance's <code>one_or_more</code> or <code>zero_or_more</code> producer or observer slot, delivering the grown set to the running node.</p> </li> <li> <p><code>peppy stack remove</code> takes the members a copy added back out of the running sets, and refuses a removal that would empty a <code>one_or_more</code> slot, naming it.</p> </li> <li> <p>A running node's bound producer and observer sets, and its topic subscriptions, follow copies joining and leaving, so call <code>bound_producers()</code> or <code>sources()</code> at the point of use.</p> </li> <li> <p>Generated set slots gain a <code>bound_members()</code> accessor returning each producer with the copy its instance belongs to, and Python gains a <code>peppylib.BoundMember</code> type.</p> </li> <li> <p><code>peppy stack list</code> shows the set members each copy added under <code>Set members:</code> and marks each bound member a copy brought with <code>[copy NAME]</code>.</p> </li> <li> <p>Standalone nodes gain <code>with_bound_producer_in_copy</code> and <code>with_peer_pin_in_copy</code> builders for a binding or pair whose instance belongs to a copy.</p> </li> </ul> </article>
