v0.17.0 https://docs.peppy.bot/releases/v0-17-0/ 2026-07-14T00:00:00Z Dependency slots gain explicit cardinality, letting a slot bind to multiple producers through a uniform consumer API. <article> <header> <h1>v0.17.0</h1> <p><em>Dependency slots gain explicit cardinality, letting a slot bind to multiple producers through a uniform consumer API.</em></p> <p><small> Released on July 14, 2026 </small></p> </header> <h3>Dependency-slot cardinality</h3> <ul> <li>Dependency slots now support explicit cardinality, letting a slot bind to one or more producers instead of exactly one.</li> <li>Bindings can target multiple producers, and consumers read them through a uniform <code>bound_producers()</code> API regardless of cardinality.</li> <li>Generated producer accessors reflect each slot's cardinality: single-producer slots expose <code>bound_producer()</code> while multi-producer slots expose <code>bound_producers()</code>.</li> <li>Bindings can now specify explicit service and action targets.</li> <li>Slots declared <code>one_or_more</code> must be non-empty, and this check now applies to programmatically supplied <code>Flags</code> values as well as arrays.</li> </ul> </article>
