v0.38.0 https://docs.peppy.bot/releases/v0-38-0/ 2026-11-17T00:00:00Z Log lines now show their UTC offset and log file names use UTC with a Z suffix, making every logged time unambiguous. <article> <header> <h1>v0.38.0</h1> <p><em>Log lines now show their UTC offset and log file names use UTC with a Z suffix, making every logged time unambiguous.</em></p> <p><small> Released on November 17, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>Log file names now use UTC with a <code>Z</code> suffix (for example <code>..._100215_412Z.log</code>) and sort in time order; update any script that parses a log file name's time.</li> <li>Each log line now starts with the machine's local time plus its UTC offset (for example <code>+00:00</code>) instead of a bare time; update tooling that parses log line timestamps.</li> </ul> </article>
