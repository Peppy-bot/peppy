v0.13.0 https://docs.peppy.bot/releases/v0-13-0/ 2026-06-25T00:00:00Z Adds OAuth device-flow sign-in through the new peppy auth commands and moves schema identifiers to a slash-separated form. <article> <header> <h1>v0.13.0</h1> <p><em>Adds OAuth device-flow sign-in through the new peppy auth commands and moves schema identifiers to a slash-separated form.</em></p> <p><small> Released on June 25, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>Schema identifiers now use a slash separator (<code>node/v1</code>, <code>interface/v1</code>, <code>launcher/v1</code>); update the schema references in your <code>peppy.json5</code> to the new slash-separated form.</li> </ul> <h3>Authentication</h3> <ul> <li>Added <code>peppy auth login</code>, <code>peppy auth logout</code>, and <code>peppy auth whoami</code> to sign in, sign out, and check your current identity using the OAuth device flow.</li> </ul> </article>
