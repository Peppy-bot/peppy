v0.33.1 https://docs.peppy.bot/releases/v0-33-1/ 2026-10-12T00:00:00Z Each option in a stack_copies scope now names a robot model, which the stack.list tool reports to clients. <article> <header> <h1>v0.33.1</h1> <p><em>Each option in a stack_copies scope now names a robot model, which the stack.list tool reports to clients.</em></p> <p><small> Released on October 12, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li> <p>Every option in a <code>stack_copies</code> launcher scope must now name a <code>model</code>, the robot model id; add <code>model</code> to each option, because a scope with an option that omits it is refused.</p> </li> <li> <p>The <code>stack.list</code> tool now reports each option's <code>model</code> id, so a client can read the robot model before adding a copy, for example to show its picture.</p> </li> </ul> </article>
