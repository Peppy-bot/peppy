v0.31.2 https://docs.peppy.bot/releases/v0-31-2/ 2026-09-24T00:00:00Z Launcher axes gain a `one_or_more` cardinality, and installation now supports only Ubuntu-based Linux and Apple Silicon macOS. <article> <header> <h1>v0.31.2</h1> <p><em>Launcher axes gain a `one_or_more` cardinality, and installation now supports only Ubuntu-based Linux and Apple Silicon macOS.</em></p> <p><small> Released on September 24, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>The installer supports only Ubuntu and the Linux distributions built on it (x86_64 and aarch64) plus macOS on Apple Silicon; on Fedora, Arch, or any other system it stops before making changes.</li> </ul> <h3>Launcher copies</h3> <ul> <li>Give a launcher axis <code>cardinality: "one_or_more"</code> to run it as named copies with a floor of one: every launch must start at least one, from <code>deployments</code> or <code>--join</code>, and <code>stack remove</code> refuses the last.</li> </ul> </article>
