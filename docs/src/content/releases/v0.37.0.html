v0.37.0 https://docs.peppy.bot/releases/v0-37-0/ 2026-11-15T00:00:00Z Container nodes run in Docker and Podman, under a root daemon, and on minimal hosts, and the container setup does more. <article> <header> <h1>v0.37.0</h1> <p><em>Container nodes run in Docker and Podman, under a root daemon, and on minimal hosts, and the container setup does more.</em></p> <p><small> Released on November 15, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li> <p>Building a Rust node now requires Rust 1.100 or later; update your Rust toolchain before you build.</p> </li> <li> <p><code>peppy container setup</code> installs the three distribution packages container nodes need (<code>uidmap</code>, <code>squashfs-tools</code>, and <code>fuse2fs</code>) and works inside Docker and Podman containers.</p> </li> <li> <p>A daemon now starts when <code>newuidmap</code>, <code>mksquashfs</code>, or <code>fuse2fs</code> is missing, running its other nodes and refusing each container build with the command that installs the missing package.</p> </li> <li> <p><code>peppy container status</code> reports every prerequisite, tests the kernel user namespace, shows how nodes get their image files, and takes <code>--packages</code> to check build packages alone.</p> </li> <li> <p>A daemon running as root now runs container nodes, using a user namespace for an image whose squashfs its kernel cannot mount, as on WSL2 or the NVIDIA Jetson.</p> </li> <li> <p>A non-root daemon inside a Docker or Podman container now runs container nodes, unpacking each image at start when a writable directory sits on overlayfs.</p> </li> <li> <p>Container nodes now start on a host that lacks <code>/etc/localtime</code> or <code>/etc/hosts</code>, such as a bare Ubuntu image, instead of failing on the missing bind source.</p> </li> <li> <p>Node builds on the peppy base images read Ubuntu packages from a dated snapshot for repeatable versions, falling back to the regular Ubuntu mirror when it is unavailable.</p> </li> </ul> </article>
