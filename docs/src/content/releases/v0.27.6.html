v0.27.6 https://docs.peppy.bot/releases/v0-27-6/ 2026-09-04T00:00:00Z Peppy authenticates git over SSH using the agent and identity files your ~/.ssh/config selects per host, so 1Password, Secretive, and gpg-agent work. <article> <header> <h1>v0.27.6</h1> <p><em>Peppy authenticates git over SSH using the agent and identity files your ~/.ssh/config selects per host, so 1Password, Secretive, and gpg-agent work.</em></p> <p><small> Released on September 4, 2026 </small></p> </header> <ul> <li>Git over SSH now authenticates with the agent and identity files <code>~/.ssh/config</code> selects for each host through <code>ssh -G</code>, honoring your <code>Host</code>, <code>Match</code>, <code>Include</code>, <code>IdentityAgent</code>, and <code>IdentityFile</code> settings.</li> <li>The daemon binds the agent your <code>IdentityAgent</code> names once at startup and logs which one, making 1Password, Secretive, and gpg-agent reachable even from a service installed with <code>peppy service install</code>.</li> <li>SSH credential failures now name the agent socket, the identity files offered, and any configured paths that do not exist, so a typo in <code>~/.ssh/config</code> is visible in the message.</li> </ul> </article>
