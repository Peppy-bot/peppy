v0.30.2 https://docs.peppy.bot/releases/v0-30-2/ 2026-09-19T00:00:00Z MCP and node servers take a free port when theirs is held, and a joined stack copy inherits its option's settings. <article> <header> <h1>v0.30.2</h1> <p><em>MCP and node servers take a free port when theirs is held, and a joined stack copy inherits its option's settings.</em></p> <p><small> Released on September 19, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>A <code>zero_or_more</code> axis option may be named in only one <code>deployments</code> entry now; a launcher that lists the same option twice is refused, so merge those entries into one.</li> </ul> <h3>Ports and endpoints</h3> <ul> <li>The built-in MCP server treats its <code>port</code> as a preference and takes an OS-assigned loopback port when another process holds it, so any number of MCP instances run on one machine.</li> <li>Rust nodes can bind with <code>peppylib::runtime::bind_preferred</code> to take their chosen port, or an OS-assigned fallback on the same host when it is held, and learn which happened.</li> <li>Endpoint blocks that <code>stack launch</code> and <code>node run</code> print are now tinted by field when color is enabled.</li> </ul> <h3>Launch files</h3> <ul> <li>A <code>stack join</code> copy inherits its option's <code>deployments</code> entry, taking that entry's <code>with</code>, <code>arguments</code>, and <code>adjustments</code> with the join's own <code>--with</code> and <code>--set-arguments</code> on top.</li> </ul> <h3>Networking</h3> <ul> <li>In the default <code>"peer"</code> topology a node session binds a network-reachable <code>0.0.0.0</code> listener on an ephemeral port; use <code>"router"</code> for a deployment that must not accept inbound peer links.</li> </ul> <h3>Core-node functions</h3> <ul> <li><code>stack.list</code> now returns two more fields, <code>copies</code> and <code>shutdown_grace_secs</code>, beside its node graph and daemon identity.</li> </ul> </article>
