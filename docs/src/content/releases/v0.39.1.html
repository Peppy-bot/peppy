v0.39.1 https://docs.peppy.bot/releases/v0-39-1/ 2026-11-26T00:00:00Z Adds a `peppy update` command to install releases in place and lets `env_from_launch` offer several variable sets through `any_of`. <article> <header> <h1>v0.39.1</h1> <p><em>Adds a `peppy update` command to install releases in place and lets `env_from_launch` offer several variable sets through `any_of`.</em></p> <p><small> Released on November 26, 2026 </small></p> </header> <h3>Updating peppy</h3> <ul> <li>Run <code>peppy update</code> to download, verify, and install the latest peppy release in place.</li> <li>Run <code>peppy update --check</code> to see whether a newer release is available without installing anything.</li> <li>Pass <code>--version &lt;version&gt;</code> to install a named release, including an older one, or <code>--force</code> to reinstall the current one.</li> <li>Pass <code>-y</code> to skip the confirmation prompt shown when the daemon is running user nodes.</li> </ul> <h3>Launch variables</h3> <ul> <li><code>env_from_launch</code>, and the <code>set_env_from_launch</code> adjustment, now accept an <code>any_of</code> of variable sets, and the instance takes the first set that its environment holds complete.</li> <li><code>peppy stack resolve</code> now reports each <code>any_of</code> of a launch together with its sets.</li> </ul> </article>
