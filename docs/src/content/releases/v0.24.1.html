v0.24.1 https://docs.peppy.bot/releases/v0-24-1/ 2026-08-17T00:00:00Z Launchers can now declare `constraints`, including `forbids`, that refuse incompatible selections in the composition model and explain each refusal. <article> <header> <h1>v0.24.1</h1> <p><em>Launchers can now declare `constraints`, including `forbids`, that refuse incompatible selections in the composition model and explain each refusal.</em></p> <p><small> Released on August 17, 2026 </small></p> </header> <h3>Launcher constraints</h3> <ul> <li>Launcher definitions accept a new <code>constraints</code> block that turns invalid combinations into selection refusals in the composition model, rejecting incompatible choices before a launch is composed.</li> <li>The <code>forbids</code> rule declares selections that cannot be combined, and refusal messages lead with the choice that triggered them so it is clear which selection to change.</li> <li>Constraint diagnostics name the constraint that shadows an unreachable one and flag a bare launch that exceeds the allowed ceiling.</li> </ul> </article>
