v0.8.0 https://docs.peppy.bot/releases/v0-8-0/ 2026-04-16T00:00:00Z Add support for repositories <article> <header> <h1>v0.8.0</h1> <p><em>Add support for repositories</em></p> <p><small> Released on April 16, 2026 </small></p> </header> <h2>What's Changed</h2> <p><strong>✨ Highlight: Repositories</strong> — this release introduces first-class <a href="/advanced_guides/repositories/">repositories</a>, a new way to tell peppy where to discover nodes. Register local directories, git repositories (with optional branch/tag pinning via <code>--ref</code>), or HTTP endpoints with <code>peppy repo add</code>, then run <code>peppy repo refresh</code> to build a cached index of every available node. Once indexed, nodes can be added by their short <code>name:tag</code> form (e.g. <code>peppy node add uvc_camera:0.1.0</code>) and launched in the node stack without pointing at a path or URL. <ul>
