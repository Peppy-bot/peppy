v0.38.3 https://docs.peppy.bot/releases/v0-38-3/ 2026-11-20T00:00:00Z Peppy is now open source under the Apache License 2.0, and stack resolve can resolve many launcher selections in one run. <article> <header> <h1>v0.38.3</h1> <p><em>Peppy is now open source under the Apache License 2.0, and stack resolve can resolve many launcher selections in one run.</em></p> <p><small> Released on November 20, 2026 </small></p> </header> <ul> <li>Peppy is now open source under the Apache License 2.0, so you can use, modify, and distribute it for free, including in a commercial product or service.</li> <li><code>peppy stack resolve --selections FILE</code> resolves every selection a file lists in one run and prints one JSON record per line for a program to read.</li> <li><code>peppy stack resolve</code> and <code>peppy stack list --json</code> now print their machine-readable data alone on stdout and send log lines to stderr.</li> </ul> </article>
