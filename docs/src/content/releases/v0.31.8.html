v0.31.8 https://docs.peppy.bot/releases/v0-31-8/ 2026-10-02T00:00:00Z Python builds can use a PyPI mirror and cache what uv downloads, and slow crate downloads no longer trip the build idle timeout. <article> <header> <h1>v0.31.8</h1> <p><em>Python builds can use a PyPI mirror and cache what uv downloads, and slow crate downloads no longer trip the build idle timeout.</em></p> <p><small> Released on October 2, 2026 </small></p> </header> <h3>Container builds</h3> <ul> <li>Set <code>pypi_mirror</code> in <code>peppy_config.json5</code> to a mirror's packages base URL to download the PyPI files a Python build's <code>uv.lock</code> pins from that mirror instead of PyPI.</li> <li>Python container builds on the peppy base image now cache the packages and interpreters uv downloads, so a rebuild fetches neither again.</li> <li>Container builds expose a <code>PEPPY_DOWNLOAD_CACHE</code> directory a def can use to cache files it downloads, keyed by their sha256.</li> <li>Builds run cargo with progress always on, so a slow crate download keeps reporting progress and no longer trips the build idle timeout.</li> </ul> <h3>MCP</h3> <ul> <li>On the per-robot surface, a refused member error now also names the other targets the robot fills with a member of that name.</li> </ul> <h3>Daemon</h3> <ul> <li>On Linux, the daemon's managed Zenoh router now ends the moment the daemon process dies, so an unclean daemon death no longer leaves a router holding its port.</li> </ul> </article>
