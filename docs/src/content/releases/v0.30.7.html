v0.30.7 https://docs.peppy.bot/releases/v0-30-7/ 2026-09-22T00:00:00Z Add `peppy stack build` to build every node a launch would run, replacing the node stack without starting anything. <article> <header> <h1>v0.30.7</h1> <p><em>Add `peppy stack build` to build every node a launch would run, replacing the node stack without starting anything.</em></p> <p><small> Released on September 22, 2026 </small></p> </header> <ul> <li><code>peppy stack build &lt;launcher&gt;</code> builds every node a launch would run and replaces the node stack without starting any instance; it takes every flag <code>peppy stack launch</code> takes, including <code>--rebuild</code>.</li> <li>A later <code>peppy stack launch</code> with the same launcher, placement, and <code>--with</code> words reuses those builds, so you can build onto a disk image that boots ready to launch.</li> <li>After a build, <code>peppy stack list</code> shows each node <code>Ready</code> with <code>0</code> instances, and <code>peppy stack join</code> is refused until a <code>peppy stack launch</code> starts the stack.</li> </ul> </article>
