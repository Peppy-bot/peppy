v0.39.0 https://docs.peppy.bot/releases/v0-39-0/ 2026-11-21T00:00:00Z Container nodes lose host-path run flags; MCP endpoints, the router, and exclusive datastore keys stay local. <article> <header> <h1>v0.39.0</h1> <p><em>Container nodes lose host-path run flags; MCP endpoints, the router, and exclusive datastore keys stay local.</em></p> <p><small> Released on November 21, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li> <p>A node manifest's <code>apptainer_run_extra_args</code> no longer accepts flags that mount or read host paths (<code>--bind</code>, <code>--mount</code>, <code>--home</code>, <code>--overlay</code>, and others); give the node its host paths through <code>mount_paths</code> instead.</p> </li> <li> <p>Node MCP endpoints refuse any request that carries an <code>Origin</code> header or a non-loopback <code>Host</code>, so a web page that a browser opens on another site cannot reach them.</p> </li> <li> <p>The managed Zenoh router listens on the loopback interface only; run your own router and set <code>zenoh.external</code> when the network must reach it.</p> </li> <li> <p>Exclusive datastore keys belong to instances on the local core node, so a federated instance on another machine cannot own, change, or remove them even when it reuses an instance id.</p> </li> </ul> </article>
