v0.31.5 https://docs.peppy.bot/releases/v0-31-5/ 2026-09-30T00:00:00Z New MCP picture tools, camera blobs, and progress-bounded actions; --nv GPU on Jetson; launcher adjustments reworked. <article> <header> <h1>v0.31.5</h1> <p><em>New MCP picture tools, camera blobs, and progress-bounded actions; --nv GPU on Jetson; launcher adjustments reworked.</em></p> <p><small> Released on September 30, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>A launcher option no longer accepts a bare list of fragments; write several files as <code>{ fragments: ["a.json5", "b.json5"] }</code>, the object form that also carries the option's own <code>adjustments</code>.</li> <li>A fragment may adjust only the instances it deploys; move writes to other instances into the launcher's <code>adjustments</code>, at the top level or under the option that selects the fragment.</li> <li>An MCP read of a topic with a <code>representation</code> returns its frame as a separate typed blob, removed from the JSON document and its schema; <code>resources/list</code> now reports the blob's image MIME type.</li> </ul> <h3>MCP exposures</h3> <ul> <li>A topic with a <code>jpeg</code> representation can declare a <code>picture</code> tool that returns the latest frame as an image beside the rest of the message.</li> <li>An action tool can set <code>progress_timeout_ms</code> instead of <code>deadline_ms</code> to bound a goal by its time without progress; it needs a feedback topic and no confirmation gate.</li> <li>A cancelled action goal now returns the provider's result, in the tool error for a call or the status message for a task, and says why it was cancelled.</li> </ul> <h3>Containers</h3> <ul> <li><code>--nv</code> containers on an NVIDIA Jetson now receive every driver library from the host's L4T container manifest, so CUDA and graphics run there as on desktop.</li> </ul> <h3>Actions</h3> <ul> <li>Unread action feedback buffers the newest messages, drops the oldest when full while always keeping the stream's end, and never blocks reading the goal's result.</li> </ul> </article>
