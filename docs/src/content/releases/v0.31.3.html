v0.31.3 https://docs.peppy.bot/releases/v0-31-3/ 2026-09-25T00:00:00Z Repository refresh gains --strict and can pin a repository to a tag or commit; one_or_more axes run as launcher copies. <article> <header> <h1>v0.31.3</h1> <p><em>Repository refresh gains --strict and can pin a repository to a tag or commit; one_or_more axes run as launcher copies.</em></p> <p><small> Released on September 25, 2026 </small></p> </header> <ul> <li>Run <code>peppy repo refresh --strict</code> to fail the command when any repository cannot be read, so CI and release checks stop instead of continuing.</li> <li>A git repository's <code>ref</code> can name a tag or a commit that is not a branch head, and <code>peppy repo refresh</code> fetches it before reading the repository.</li> <li>A launcher with a <code>one_or_more</code> axis in its <code>components</code> runs that axis as copies you can add and remove while its other instances keep running.</li> </ul> </article>
