v0.31.6 https://docs.peppy.bot/releases/v0-31-6/ 2026-10-01T00:00:00Z Record an endpoint's state-changing calls, answer a service with a picture, and read the first message that arrives after the read. <article> <header> <h1>v0.31.6</h1> <p><em>Record an endpoint's state-changing calls, answer a service with a picture, and read the first message that arrives after the read.</em></p> <p><small> Released on October 1, 2026 </small></p> </header> <h3>The call record</h3> <ul> <li>Declare a <code>call_record</code> in an exposure to publish a read-only tool that lists the last state-changing calls (mutating services and actions), newest first, with the client, arguments, outcome, and duration of each.</li> </ul> <h3>Services that answer with a picture</h3> <ul> <li>A service can declare a <code>representation</code> to answer its response's frame as an image beside the rest of the response, the way a picture tool does, with <code>on_oversize</code> to downscale a frame that exceeds <code>max_result_bytes</code>.</li> </ul> <h3>Reads return the next message</h3> <ul> <li>A topic read, and a picture tool, now answers with the first message the endpoint receives after the read, so a client that changes state and reads at once sees the result of its change, bounded by <code>freshness.max_age_ms</code>.</li> </ul> </article>
