v0.15.0 https://docs.peppy.bot/releases/v0-15-0/ 2026-07-05T00:00:00Z Nodes can now declare, establish, and dissolve pairings with one another, and serve restarts and shutdowns are more reliable. <article> <header> <h1>v0.15.0</h1> <p><em>Nodes can now declare, establish, and dissolve pairings with one another, and serve restarts and shutdowns are more reliable.</em></p> <p><small> Released on July 5, 2026 </small></p> </header> <h3>Node pairing</h3> <ul> <li>Nodes can now declare, establish, and dissolve pairings (peer links) with one another at runtime.</li> <li>Each paired node exposes a <code>LINK_ID</code> and a <code>pairings</code> view in its generated module so node code can identify and work with its active links.</li> <li><code>peppy stack list</code> now shows an "Instance pairings" section listing the active pairings between running instances.</li> <li>Malformed pairing targets are now rejected, and pairing delivery is protected against a link being dissolved concurrently.</li> </ul> <h3>Serve reliability</h3> <ul> <li><code>peppy serve</code> no longer drops shutdown signals or races when restarting, so restarts and shutdowns now behave reliably.</li> </ul> </article>
