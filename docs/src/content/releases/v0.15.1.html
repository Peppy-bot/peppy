v0.15.1 https://docs.peppy.bot/releases/v0-15-1/ 2026-07-07T00:00:00Z Adds remote core node targeting and collision detection, renames the serve command and the shared-directory variable. <article> <header> <h1>v0.15.1</h1> <p><em>Adds remote core node targeting and collision detection, renames the serve command and the shared-directory variable.</em></p> <p><small> Released on July 7, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>The <code>PEPPYOS_SHARED_DIR</code> environment variable has been renamed to <code>PEPPY_SHARED_DIR</code>; update your environment so the shared directory stays configured.</li> </ul> <h3>Core node targeting</h3> <ul> <li>The <code>--core-node</code> flag can now target a remote core node and is accepted by <code>node add</code>, <code>node sync</code>, and <code>repo add</code>.</li> <li>The <code>--core-node</code> flag is now validated as the command is parsed, so invalid values are reported immediately.</li> <li>peppy now detects core node name collisions.</li> </ul> <h3>Serve reliability</h3> <ul> <li><code>peppy service serve</code> now shuts down cleanly when an error occurs during startup.</li> </ul> </article>
