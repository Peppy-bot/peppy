v0.31.4 https://docs.peppy.bot/releases/v0-31-4/ 2026-09-25T00:00:00Z The default hubs now track your Peppy version through the new `@{peppy-release}` ref. <article> <header> <h1>v0.31.4</h1> <p><em>The default hubs now track your Peppy version through the new `@{peppy-release}` ref.</em></p> <p><small> Released on September 25, 2026 </small></p> </header> <ul> <li>New installs pin the default hubs with <code>ref: "@{peppy-release}"</code>, which reads the <code>peppy-release/&lt;version&gt;</code> tag matching your Peppy version, so their content changes only when you install another version.</li> <li>Set a git repository's <code>ref</code> to <code>@{peppy-release}</code> in <code>repositories.json5</code>, or pass <code>--ref @{peppy-release}</code> to <code>peppy repo add</code> and <code>peppy repo exclude</code>, to track your version's hub content.</li> <li>Existing <code>repositories.json5</code> entries are never rewritten, so a default hub already on <code>main</code> keeps reading <code>main</code>; set its <code>ref</code> to <code>@{peppy-release}</code> to follow your Peppy version.</li> <li>After you install a different Peppy version, the daemon reads the <code>@{peppy-release}</code> repositories again at its next start, before it answers any request.</li> <li><code>peppy repo list</code>, search, and <code>peppy repo show</code> label a repository on <code>@{peppy-release}</code> with the ref it resolves to, such as <code>reads peppy-release/v0.32.0</code>.</li> </ul> </article>
