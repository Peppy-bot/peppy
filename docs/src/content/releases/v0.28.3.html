v0.28.3 https://docs.peppy.bot/releases/v0-28-3/ 2026-09-14T00:00:00Z Environment variables now reach container nodes whole, and removing a stack copy restores the vacancies it filled. <article> <header> <h1>v0.28.3</h1> <p><em>Environment variables now reach container nodes whole, and removing a stack copy restores the vacancies it filled.</em></p> <p><small> Released on September 14, 2026 </small></p> </header> <ul> <li>Environment variable values that contain commas now reach container nodes whole, instead of being split into separate variables.</li> <li>Removing a copy from a running stack now restores the vacant slots it had filled, unless another copy still occupies them.</li> <li>A container bind mount whose source or destination path contains <code>:</code> or <code>,</code> is now refused with a clear error instead of being silently misparsed.</li> </ul> </article>
