v0.28.5 https://docs.peppy.bot/releases/v0-28-5/ 2026-09-16T00:00:00Z CPU a build burns now counts as build progress, so long silent compiles no longer trip the build idle timeout. <article> <header> <h1>v0.28.5</h1> <p><em>CPU a build burns now counts as build progress, so long silent compiles no longer trip the build idle timeout.</em></p> <p><small> Released on September 16, 2026 </small></p> </header> <ul> <li>A <code>%post</code> step or a <code>build_cmd</code> that compiles silently no longer trips the build idle timeout: the CPU it burns now counts as progress alongside bytes written to disk.</li> <li>Build progress feedback now appears during <code>build_cmd</code> runs too, and every progress line reports CPU time consumed as well as bytes written.</li> <li>Peppy refuses a container bind path containing a <code>:</code> or a <code>,</code> on either side, because Apptainer's mount spec reads both as separators with no way to escape them.</li> <li>Removing a stack copy that had paired into a stack instance's vacant slot now restores that slot to vacant, as the original launch declared it.</li> </ul> </article>
