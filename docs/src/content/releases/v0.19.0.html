v0.19.0 https://docs.peppy.bot/releases/v0-19-0/ 2026-07-24T00:00:00Z Actions adopt the goal-ack envelope and split goal/result endpoints; the generator now honors declared goal response schemas. <article> <header> <h1>v0.19.0</h1> <p><em>Actions adopt the goal-ack envelope and split goal/result endpoints; the generator now honors declared goal response schemas.</em></p> <p><small> Released on July 24, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>Actions now use the framework goal-ack envelope for goal acknowledgements; update any consumer that parses goal acknowledgement messages to the new envelope format.</li> <li>Action endpoints are now split into separate goal and result endpoint types; update any configuration or code that referenced the previous combined action endpoint type.</li> <li>Generated goal responses no longer include an error field; update any code that read that field.</li> </ul> <h3>Code generation</h3> <ul> <li>The code generator now honors the goal response schemas you declare, so generated goal responses match your declaration; regenerate to pick up the change.</li> </ul> <h3>Documentation</h3> <ul> <li>The guide pages have been revised to fix inconsistencies and formatting issues.</li> </ul> </article>
