v0.25.2 https://docs.peppy.bot/releases/v0-25-2/ 2026-08-20T00:00:00Z The generated test harness serves the daemon clock, so you can boot nodes in sim time and drive it, or skew wall time. <article> <header> <h1>v0.25.2</h1> <p><em>The generated test harness serves the daemon clock, so you can boot nodes in sim time and drive it, or skew wall time.</em></p> <p><small> Released on August 20, 2026 </small></p> </header> <ul> <li>Boot a node in sim time under the generated test harness with <code>use_sim_time</code> and drive its virtual clock yourself with <code>harness.clock.tick(...)</code>, with no time existing until you tick.</li> <li>Skew the wall clock the harness serves with <code>harness.clock.set_offset_ns(...)</code> to exercise a node's clock-offset handling without touching the host clock.</li> <li>Run standalone (daemon-less) nodes in sim time with <code>StandaloneConfig.with_use_sim_time(...)</code>, which no longer requires a real daemon stack.</li> <li><code>peppygen.clock.init</code> now rebinds when a different node initializes it, so consecutive test-harness boots in one process each read their own clock.</li> </ul> </article>
