v0.35.1 https://docs.peppy.bot/releases/v0-35-1/ 2026-10-26T00:00:00Z Lease and halt robots with peppy fleet, call daemon interfaces from nodes, and call any contract with the codec API. <article> <header> <h1>v0.35.1</h1> <p><em>Lease and halt robots with peppy fleet, call daemon interfaces from nodes, and call any contract with the codec API.</em></p> <p><small> Released on October 26, 2026 </small></p> </header> <h3>Robot leases and the halt</h3> <ul> <li>Run <code>peppy fleet list</code>, <code>peppy fleet halt</code>, and <code>peppy fleet clear-halt</code> to inspect the fleet, halt every client that moves a robot, and clear the halt.</li> <li>A node with a scoped <code>fleet</code> daemon target holds a <code>lease</code> goal to take, offer, and open robot leases, and follows the fleet's listing and changes.</li> <li>MCP servers, <code>peppy node call</code>, and lease holders check the daemon before calling a member marked <code>moves_robot</code>, and refuse it during a halt or on a robot another client leases.</li> <li>Mark a launcher axis with <code>role: "robot_commander"</code> so the fleet listing names each robot's commander.</li> </ul> <h3>Daemon targets</h3> <ul> <li>List daemon interfaces in a node's <code>manifest.depends_on.daemon</code>; the generated client calls them on the daemon that runs the instance.</li> <li>Scope each daemon target in a launcher's <code>daemon_scopes</code>, or leave it unserved with <code>{ vacant: "&lt;why&gt;" }</code>.</li> <li>A node reaches the daemon only through its daemon targets; the daemon refuses stack-changing raw calls from nodes of the stack.</li> </ul> <h3>The codec API and contract metadata</h3> <ul> <li>Set <code>codec_api: true</code> in a node's <code>execution</code> block to get the codec API, which parses any contract (comments included), converts its messages, and calls its members.</li> <li>Give contract members a <code>marks</code> list (peppy defines <code>moves_robot</code>), string fields a closed <code>$enum</code> set, and fields a <code>$marks</code> list, all readable through the codec API.</li> </ul> <h3>MCP exposures</h3> <ul> <li><code>stack_copies:v1</code> <code>list</code> now reports each option's <code>kind</code>, whether each copy is <code>running</code>, and the stack's <code>launcher</code>, and <code>join</code> and <code>remove</code> can refuse with <code>halted</code> or <code>leased</code>.</li> </ul> </article>
