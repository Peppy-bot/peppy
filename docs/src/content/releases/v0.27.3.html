v0.27.3 https://docs.peppy.bot/releases/v0-27-3/ 2026-09-02T00:00:00Z Peppy now reads git repositories over SSH, so private repositories are reachable without embedding a credential in your config. <article> <header> <h1>v0.27.3</h1> <p><em>Peppy now reads git repositories over SSH, so private repositories are reachable without embedding a credential in your config.</em></p> <p><small> Released on September 2, 2026 </small></p> </header> <ul> <li>You can now give <code>peppy repo add</code>, <code>peppy node add</code>, and <code>git</code> entries in <code>repositories.json5</code> an SSH URL (<code>git@host:owner/repo.git</code> or <code>ssh://</code>) to reach a private repository, authenticating through your ssh-agent and <code>~/.ssh</code> keys the way <code>ssh</code> does.</li> </ul> </article>
