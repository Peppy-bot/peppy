v0.23.2 https://docs.peppy.bot/releases/v0-23-2/ 2026-08-11T00:00:00Z Absent optional node dependencies are now accepted when the slot allows an empty bound set, with clearer guides. <article> <header> <h1>v0.23.2</h1> <p><em>Absent optional node dependencies are now accepted when the slot allows an empty bound set, with clearer guides.</em></p> <p><small> Released on August 11, 2026 </small></p> </header> <h3>Dependencies</h3> <ul> <li>A node dependency may now be absent when its slot admits an empty set of bounds, so optional dependencies no longer need to be present to satisfy resolution.</li> </ul> <h3>Documentation</h3> <ul> <li>The guides now document how to add an optional dependency and correct the wording used to describe the dependency walk.</li> <li>The guides now name the both-sources failure and describe the add-path cache fallback.</li> <li>The guides now accurately describe worklist deduplication and launch vacancy.</li> </ul> </article>
