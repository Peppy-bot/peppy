v0.25.7 https://docs.peppy.bot/releases/v0-25-7/ 2026-08-22T00:00:00Z `stack resolve` now checks link rules without a daemon, and generated bindings decode string-list payload fields. <article> <header> <h1>v0.25.7</h1> <p><em>`stack resolve` now checks link rules without a daemon, and generated bindings decode string-list payload fields.</em></p> <p><small> Released on August 22, 2026 </small></p> </header> <h3><code>stack resolve</code></h3> <ul> <li><code>stack resolve</code> now checks the flat plan against the link rules it can verify without a daemon (slot keys, vacancies, and pairing coverage) and fails early when one breaks.</li> <li>The resolution report ends with a line saying whether those link rules were checked, or why the check was skipped and to run <code>peppy repo refresh</code>.</li> </ul> <h3>Message payloads</h3> <ul> <li>Topic and action payloads can now include string-list fields (<code>$type: "array"</code> with <code>$items: "string"</code>), and the generated bindings decode them.</li> </ul> </article>
