v0.30.1 https://docs.peppy.bot/releases/v0-30-1/ 2026-09-18T00:00:00Z Nodes can now serve web pages and MCP endpoints, and peppy reports their URLs across its commands. <article> <header> <h1>v0.30.1</h1> <p><em>Nodes can now serve web pages and MCP endpoints, and peppy reports their URLs across its commands.</em></p> <p><small> Released on September 18, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li><code>peppy stack list</code> endpoint output changed: the table adds <code>KIND</code> and <code>LABEL</code> columns and <code>--json</code> lists each endpoint as <code>{label, kind, urls}</code> rather than a URL string — update your parsers.</li> </ul> <h3>Serving pages and MCP endpoints</h3> <ul> <li>Declare a node's served endpoints under <code>execution.endpoints</code> in <code>peppy.json5</code> — each with a label, a <code>page</code> or <code>mcp</code> kind, and a description — and announce each bound socket from <code>setup</code> with <code>announce_endpoint</code>.</li> <li><code>peppy node run</code>, <code>peppy stack launch</code>, and <code>peppy stack join</code> now end by printing the URLs each started instance serves, grouped under <code>Web pages:</code> and <code>MCP endpoints:</code> headings.</li> <li><code>peppy node info</code> and <code>peppy stack list</code> now show each running instance's endpoints with their kind, label, and every URL.</li> </ul> <h3>Auditing composed launches</h3> <ul> <li><code>peppy stack resolve</code> now checks link rules for git-published nodes too, reading their manifests from the checkout cache <code>peppy repo refresh</code> fills instead of skipping them, without touching the network.</li> </ul> </article>
