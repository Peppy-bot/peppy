v0.38.4 https://docs.peppy.bot/releases/v0-38-4/ 2026-11-20T00:00:00Z You can mark fields of nested objects and of an array's object items as `$optional`, with clearer time and format errors. <article> <header> <h1>v0.38.4</h1> <p><em>You can mark fields of nested objects and of an array's object items as `$optional`, with clearer time and format errors.</em></p> <p><small> Released on November 20, 2026 </small></p> </header> <ul> <li>Mark a field of a nested object, or of the objects an array holds, as <code>$optional</code>; the published MCP schema then leaves it out of that object's <code>required</code>.</li> <li>A time value that cannot convert now gives an error that shows the expected form: an RFC 3339 UTC string with up to nine fractional-second digits.</li> <li>Building a message codec in Python from an invalid message format now reports the path of the offending field.</li> </ul> </article>
