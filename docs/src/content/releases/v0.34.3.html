v0.34.3 https://docs.peppy.bot/releases/v0-34-3/ 2026-10-23T00:00:00Z Nodes stop promptly when a replacement daemon starts, and repository reads fetch only the one commit a ref names. <article> <header> <h1>v0.34.3</h1> <p><em>Nodes stop promptly when a replacement daemon starts, and repository reads fetch only the one commit a ref names.</em></p> <p><small> Released on October 23, 2026 </small></p> </header> <h3>Daemon restart and orphan cleanup</h3> <ul> <li>A node now shuts itself down at the first heartbeat of a new daemon of its core node, instead of waiting out the daemon grace period, so your next launch starts it again.</li> <li>The grace period now resets only on heartbeats from the node's own daemon, so a restart of just the daemon's messaging router keeps the nodes running.</li> </ul> <h3>Repository reads</h3> <ul> <li>Reading a <code>git</code> repository now fetches only the single commit its <code>ref</code> names, at depth 1 with no history and no other branch or tag, rather than shallow-cloning every branch.</li> <li>A <code>ref</code> that is not a commit hash resolves as written, then as a branch, then as a tag, and with no <code>ref</code> Peppy reads the commit at <code>HEAD</code>.</li> </ul> </article>
