v0.24.0 https://docs.peppy.bot/releases/v0-24-0/ 2026-08-16T00:00:00Z Compose launchers from fragments with --with selections and a new stack resolve command, plus sturdier container builds. <article> <header> <h1>v0.24.0</h1> <p><em>Compose launchers from fragments with --with selections and a new stack resolve command, plus sturdier container builds.</em></p> <p><small> Released on August 16, 2026 </small></p> </header> <h3>Launch composition</h3> <ul> <li>Peppy parses composed launchers and flattens a launcher selection into a single flat launcher.</li> <li><code>--with</code> selections are resolved on the coordinator, and the new <code>stack resolve</code> command reports the resolved stack.</li> <li>A single launcher fragment can no longer both replace and append to the same slot; peppy rejects fragments that do.</li> <li>Launcher fragment validation covers previously missed cases, tightening composition safety.</li> </ul> <h3>Containers</h3> <ul> <li>Container builds are retried automatically when the base image fetch fails transiently.</li> <li>Peppy checks for <code>fuse2fs</code> on hosts that run rootless Apptainer containers.</li> </ul> <h3>Networking</h3> <ul> <li>Peppy supports a wildcard peer listener for peer discovery.</li> </ul> <h3>Output</h3> <ul> <li>Peppy announces a cached-checkout reuse once per checkout population.</li> </ul> </article>
