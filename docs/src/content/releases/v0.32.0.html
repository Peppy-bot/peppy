v0.32.0 https://docs.peppy.bot/releases/v0-32-0/ 2026-10-08T00:00:00Z A topic can declare retention so a consumer that subscribes later reads the producer's newest messages first. <article> <header> <h1>v0.32.0</h1> <p><em>A topic can declare retention so a consumer that subscribes later reads the producer's newest messages first.</em></p> <p><small> Released on October 8, 2026 </small></p> </header> <ul> <li>An emitted or contract topic can declare <code>retention: { latest: N }</code> (up to 1024), so a consumer that subscribes later reads the producer's newest N messages before live updates.</li> <li>Re-sync a consumer after its producer changes a topic's retention: <code>peppy node sync</code> reads the policy from the producer and the generated subscription applies it.</li> <li><code>peppy node info</code> reports the retention of a topic that retains.</li> </ul> </article>
