v0.31.10 https://docs.peppy.bot/releases/v0-31-10/ 2026-10-06T00:00:00Z Export the daemon's log files to an OpenTelemetry endpoint, and keep credentials out of the source URLs it logs. <article> <header> <h1>v0.31.10</h1> <p><em>Export the daemon's log files to an OpenTelemetry endpoint, and keep credentials out of the source URLs it logs.</em></p> <p><small> Released on October 6, 2026 </small></p> </header> <ul> <li>Set <code>otlp_endpoint</code> in the daemon configuration to export the launch, add, build, run and stack logs to an OpenTelemetry collector or intake over OTLP/HTTP, and <code>otlp_min_severity</code> to limit the severity sent.</li> <li>Put export request headers, such as an API key, in the new <code>~/.peppy/conf/otlp_headers.json5</code> file.</li> <li>Git and HTTP source URLs that the daemon writes to log lines and error messages no longer carry their credentials.</li> <li>The "node not found" error now points at <code>peppy stack list</code> and <code>peppy node add &lt;dir&gt;</code> instead of a command that does not exist.</li> </ul> </article>
