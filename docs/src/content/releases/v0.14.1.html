v0.14.1 https://docs.peppy.bot/releases/v0-14-1/ 2026-07-02T00:00:00Z Bundle downloads retry transient failures, AppArmor profiles are per-install, and node run drops the legacy --link-id flag. <article> <header> <h1>v0.14.1</h1> <p><em>Bundle downloads retry transient failures, AppArmor profiles are per-install, and node run drops the legacy --link-id flag.</em></p> <p><small> Released on July 2, 2026 </small></p> </header> <h3>Breaking changes</h3> <ul> <li>The legacy <code>--link-id</code> flag has been removed from <code>node run</code>; remove it from any commands or scripts that still pass it.</li> </ul> <h3>Node downloads and runtime</h3> <ul> <li>Transient HTTP failures when downloading node bundles are now retried automatically with bounded backoff, making node setup more resilient to flaky networks.</li> <li>Empty environment variable path overrides are now treated as unset, so an empty value falls back to the default instead of being used as a literal path.</li> </ul> <h3>AppArmor</h3> <ul> <li>AppArmor profiles are now namespaced per Apptainer installation path, so multiple Apptainer installations no longer collide.</li> <li>The AppArmor fix script now shell-escapes the starter path correctly, so installation paths containing special characters work.</li> </ul> </article>
