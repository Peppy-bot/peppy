v0.25.0 https://docs.peppy.bot/releases/v0-25-0/ 2026-08-19T00:00:00Z peppy generates mock and fixtures test surfaces for Rust and Python nodes, plus a Testing guide and a scaffolded harness. <article> <header> <h1>v0.25.0</h1> <p><em>peppy generates mock and fixtures test surfaces for Rust and Python nodes, plus a Testing guide and a scaffolded harness.</em></p> <p><small> Released on August 19, 2026 </small></p> </header> <h3>Testing</h3> <ul> <li>peppy now emits mock and fixtures test surfaces into the generated <code>peppygen</code> package for both Rust and Python nodes, so you can test your nodes against generated mocks and fixtures.</li> <li>Multi-instance mock slots now carry explicit instance ids, so tests can address each instance individually.</li> <li>Optional pairing slots gain a vacant-boot knob for booting a node with the optional peer left unpaired.</li> <li>Generated mocks honor the per-interface consumer link ids you declare.</li> <li><code>peppy node init</code> now scaffolds a lib/main split and a harness smoke test for new nodes.</li> <li>A new Testing guide covers writing tests with mocks, teardown, and the cardinality knobs.</li> </ul> </article>
