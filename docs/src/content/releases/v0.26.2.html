v0.26.2 https://docs.peppy.bot/releases/v0-26-2/ 2026-08-28T00:00:00Z MCP tasks for feedback-less actions now settle on their result, and release artifacts no longer carry the build machine's identity. <article> <header> <h1>v0.26.2</h1> <p><em>MCP tasks for feedback-less actions now settle on their result, and release artifacts no longer carry the build machine's identity.</em></p> <p><small> Released on August 28, 2026 </small></p> </header> <h3>MCP server</h3> <ul> <li>MCP tasks backed by an action that declares no feedback now settle on the provider's result instead of stalling until the task deadline.</li> </ul> <h3>Release artifacts</h3> <ul> <li>Release archives are packed with neutral ownership, so installing them as root inside a user namespace no longer fails or hands the files to a same-named local account.</li> <li>The <code>peppy</code> binary and the bundled apptainer man pages no longer embed the build machine's home directory or source paths.</li> </ul> </article>
