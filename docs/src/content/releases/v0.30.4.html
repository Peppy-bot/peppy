v0.30.4 https://docs.peppy.bot/releases/v0-30-4/ 2026-09-21T00:00:00Z Action-backed MCP tools now run their goal inside the call for clients that lack the tasks extension. <article> <header> <h1>v0.30.4</h1> <p><em>Action-backed MCP tools now run their goal inside the call for clients that lack the tasks extension.</em></p> <p><small> Released on September 21, 2026 </small></p> </header> <ul> <li>A client without the MCP tasks extension can now call an action-backed tool: the goal runs inside the call, streams feedback as progress notifications, and cancels when the call closes.</li> <li>An action-backed tool that requires confirmation still needs the tasks extension, and a client without it is refused with a clear missing-capability error.</li> <li>Stopping a daemon now waits for its container to exit before the stop completes.</li> <li>Stopping now waits for in-flight goals to finish tearing down before it returns.</li> </ul> </article>
