v0.30.3 https://docs.peppy.bot/releases/v0-30-3/ 2026-09-20T00:00:00Z Join several robots into one simulation, each bringing its own model, plus a warning-free generated test harness. <article> <header> <h1>v0.30.3</h1> <p><em>Join several robots into one simulation, each bringing its own model, plus a warning-free generated test harness.</em></p> <p><small> Released on September 20, 2026 </small></p> </header> <h3>Simulation</h3> <ul> <li>Join several robots into one simulation, each a copy bringing its own model; Isaac Sim and Waldo stand many at once, while MuJoCo stands one at a time.</li> <li>Remove a simulated robot with <code>peppy stack remove</code> and only that robot leaves; the simulation stays running for the next join.</li> <li>The simulation's model catalogue carries OpenArm v1, OpenArm v2, and SO-101, and a simulated SO-101 starts in its home posture with the jaw closed.</li> </ul> <h3>Generated test harness</h3> <ul> <li>The Rust test harness peppygen generates now compiles warning-free for a node that publishes nothing.</li> </ul> </article>
